# The fan-out is stoppable with truthful states

**The whole-project run is stoppable with TRUTHFUL per-doc states: "Stop run" on the project-run screen cancels the fan-out and documents that never settled a change render as honestly `skipped` (never "no change"); the orchestrator `runAgent` also threads a per-run `CancellationToken` so its document loop can be cut short**

The visible whole-project run IS the chat working-set fan-out (decision D23-A/#77: `_openProjectRun` -> `sendChatMessage(anchor, ...)` with the folder as the working set), a SINGLE model call anchored on one document - not `orchestrator.runAgent` as plan-27's stale anchor note assumed. So the honest, minimal implementation cancels THAT call: the run screen's command strip gains a **Stop run** control (`data-msg="stopProjectRun"`) that calls `cancelChat(anchor)` while `inFlight`; `_projectRunState` detects a stopped run from the anchor's last chat turn carrying `stopped: true` and passes a `stopped` flag into the pure `summariseProjectRun(docs, pending, stopped)` selector, which now marks every not-yet-changed tile `skipped` (a new `ProjectRunDocStatus` + `skippedDocs` total) while a changed doc keeps its work; the swarm renders a dashed "skipped" tile, a "Run stopped" heading and an "N skipped" bottom-bar clause, and the topbar shows a calm "Stopped" pill. Because the fan-out is atomic (proposals commit only at stream end), a mid-flight Stop truthfully skips every document - the honesty rule (plan 23) is satisfied without faking partial per-doc progress. **Also** (matching plan-27's literal `runAgent` intent and making the agent "Run now" fan-out cancellable): `AgentOrchestrator.runAgent(agentId, trigger, docs, token = None)` threads an optional `CancellationToken` into `IAgentRunContext.token`, and the service's `_runAgent` loop checks it between documents - stopping and reporting the remainder as `IAgentRunResult.skipped` (documents already processed keep their reviewable work, never a partial write). **Tier: our-surface** (model selector + screen renderer/editor + orchestrator/service; 0 core patches). Verified by unit tests (the plan permits unit evidence for iter 4): `summariseProjectRun` stopped -> skipped tiles + totals; `screenRender` renders the Stop run control + Live pill in flight and skipped tiles + Stopped state once stopped; `AgentOrchestrator` threads a cancelled token so the runner skips the remaining docs, and defaults to a non-cancelled token otherwise.
