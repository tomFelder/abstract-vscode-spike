# The tree rail is three tabs with folded search

**The tree rail is three tabs - Files · Context · Outline - with Search folded into Files as type-to-filter, and a quiet ＋ (new document, name-first) joining the tab strip; the full document context menu ships (Open / Open to the right / Rename inline / Duplicate / Move to… / Bind sources… / View history / Present / Delete-with-confirm)**

Three tabs read calmer than four and type-to-filter is where muscle memory looks for search in a file rail; the menu makes documents behave like documents without IDE affordances, and file ops always move the lock sidecar and re-point dependents through the existing service seams.
