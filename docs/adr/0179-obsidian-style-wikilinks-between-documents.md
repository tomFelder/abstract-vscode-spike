# Obsidian-style wikilinks between documents

**Obsidian-style `[[wikilinks]]` are the doc-to-doc link syntax: `[[` opens a filtered picker, links store as `[[Doc Name]]` in the Markdown (Obsidian-compatible), render as navigable chips, unresolved links create the doc on click; `bind:` values and `{{slot}}` tokens are untouched**

First item on the founder's notes; the linking grammar should match the tool-culture (Obsidian) the product borrows its shell feel from, and the on-disk format stays portable.
