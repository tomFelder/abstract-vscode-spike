# Chat becomes workspace-level with tabs

**Chat becomes workspace-level with chat tabs: chats belong to the workspace (not the document), a tab strip lives in the chat rail, Cmd+T opens a new chat, documents join via @-mentions; per-doc thread history remaps to "chats mentioning this doc"**

The doc-anchored single thread made Cmd+T dead and multi-topic work impossible; Cursor's workspace-chat model is the pattern the target user already knows.
