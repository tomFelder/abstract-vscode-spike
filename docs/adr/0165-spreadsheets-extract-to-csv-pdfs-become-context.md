# Spreadsheets extract to CSV, PDFs become context

**Spreadsheets become sources by EXTRACTION to per-sheet CSVs under `data/<workbook>/`, not by direct xlsx binding; PDFs become read-only `context` edges via extracted text; both parse in the node/proxy layer, never the renderer**

Settled to doc 22 §4's recommendation. The whole binding/provenance engine already speaks CSV (`file` sources with `sourceHash`/`syncedAt`, the 1p drawer on the exact row), so a workbook's sheets extract to plain CSVs (`data/<workbook>/<sheet>.csv`) that reuse the entire existing staleness/watch/provenance machinery unchanged; the workbook itself is watched with a correlated watcher and re-extracts on hash change, flagging dependents through the normal graph. A PDF maps onto the pre-existing `context[]`/`IContextEntry` influence edge (watched, hashed, stale-flagged, shown in SOURCES); its extracted text is cached as a portable plain-text file under `.abstract/knowledge/` that `_readContext` reads instead of the binary PDF (freshness still tracks the real PDF's bytes). The parsing floor (doc 21 §6.5) lives at extraction time in a pure node module (`scripts/lwd-source-extract.js`): delimiter sniffing (`,`/`;`/tab), BOM + Windows-1252 tolerance, currency/thousands/parenthesised-negative and US-vs-EU decimal parsing, dates normalised to ISO; merged-header and pivot sheets carry a NAMED limitation, never a silent misread. A scanned/image-only or password-protected PDF names itself unreadable rather than yielding empty context. Deferred (P3, honest absence): cell-level xlsx binding, formula awareness, Google Sheets, any db layer. **Tier: our-surface, 0 core patches.** New proxy routes `POST /sources/xlsx` + `/sources/pdf` (additive, lazily require SheetJS/pdf-parse so a proxy without them still serves the model routes). Verified: 10 node engine tests (`node --test`) over the parsing floor + workbook extraction + PDF readable/image-only/password branches (real SheetJS + real pdf-parse against generated PDFs); 4 browser service/tree tests (extraction writes the CSVs + manifest and surfaces the merged-header warning; the provenance drawer shows figure → CSV → workbook; a readable PDF becomes a context edge with cached text while an image-only PDF names itself unreadable and creates no edge; the tree classifies workbooks/PDFs as "Use as source" rows); live proxy curl of both routes; artefacts under `docs/plans/40-verify/a3-sources/`.
