# The project-run grid runs a live fan-out

**The project-run swarm grid + progress + bottom-bar totals are driven by a LIVE whole-project chat fan-out kicked from the screen, read purely through `summariseProjectRun` + `isChatBusy`, with the in-flight spinner as a live overlay. 0 core patches.**

Iter 3 makes C4's right pane real. **Run kick** (`ScreenEditor._openProjectRun` → new `_kickProjectRun`, `screenEditor.ts`): open the `project-run` screen, then load an anchor document (`docs[0]`; `sendChatMessage` needs a loaded anchor state), `addFolderToWorkingSet(anchor)` (every folder `.md`), resolve the transcript source against the loaded anchor's `getMentionableFiles`, `@mention` it into the sent text, and `sendChatMessage(anchor, instruction)` so `_chatRespondMulti` fans one instruction across the working set in a SINGLE model call (decision 62 / #77). The displayed instruction defaults to "Extract the decisions from the 3 March security review and apply the required changes across every affected policy." sourced to `Security Review - 3 Mar.txt` when the Agents action passes none. **Swarm read** (`screenRender.ts`): tiles + totals come from the pure `summariseProjectRun(projectRunDocs, getAllPending())` selector; the `working` (spinner + `reviewing…`) state is a live overlay — every project doc while `isChatBusy(anchor)` is true, empty once settled — because the whole-project fan-out is one call, so the whole swarm spins together then settles (truthful to the architecture, not per-doc trickle). Progress = settled docs / total; bottom bar = `totalChanges` / `changedDocs` / live working count / (`unchangedDocs` − working). **Live-update mechanism:** reuses the EXISTING `ScreenEditor._inputDisposables` subscription to `livingDocs.onDidChange` → `_render`; `_render` recomputes the run state each time from the live service (new `_projectRunState()`), so no new event loop and no new disposables. **Small enabling change:** `_scanFolderDocs` now also globs `.txt` so a real transcript source (`.txt`) is mentionable/readable — the working set stays `.md`-only (it uses `listDocuments`/`_collectDocs`, `.md`-gated), so `.txt` only becomes a mentionable *source*, which is correct.
