**The Knowledge screen becomes the project's real source library: a `listSources()` projection (source registry) rendered as a Project SOURCES table + per-source detail drawer, with an honest "Soon" Organization tab - the fabricated mission/OKR decision-stack is removed**

Settled to the plan's recommendation (unattended).
