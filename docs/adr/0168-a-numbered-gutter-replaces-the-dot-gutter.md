# A numbered gutter replaces the dot gutter

**The numbered gutter replaces the 30px dot gutter, revising plan-20 §C2: a 70px line-numbered rail (JetBrains Mono 11px, idle `#C6CAD2`), one number per Markdown line/block (D1 wrap rule, wrapped rows blank), provenance riding the numbers (bound = accent number + 9px dot; pending = attention number + 3px bar), and numbers becoming shared line addresses used by chat, review, proposals, Home cards and the Agents ledger**

The dot gutter answered "which lines are alive" but gave conversation no vocabulary; Obsidian's numbers showed that a quiet numbered rail does both. Persistent references carry block/claim ids - the printed number is computed at render time, so history degrades gracefully as documents change.
