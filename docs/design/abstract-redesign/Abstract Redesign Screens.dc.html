Rules. Sans = system stack; mono = IBM Plex Mono. Mono is reserved for section labels, kind badges, and provenance facts (file names, cells, synced-when, line numbers, version chips) — never for metadata values or model ids. Weights 400/600 only. Sentence case everywhere, including buttons. Radii: 8 controls · 10 inputs · 12–14 cards · 999 pills and dots. Spacing on the 4px scale. One stroke: 1px hairline.
